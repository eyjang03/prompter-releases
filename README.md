# Prompter for Mac

Release downloads for Prompter. This repository holds no source code.

To install, open the [latest release](https://github.com/eyjang03/prompter-releases/releases/latest), download the `.dmg`, open it and drag Prompter to Applications. Prompter needs an Apple silicon Mac with macOS 26 or later.

Prompter is not notarized by Apple. If macOS blocks it the first time, open System Settings > Privacy & Security, choose Open Anyway and confirm.

Installed copies update themselves: they read `macos.json` here, download the newer `.zip` and install it when Prompter quits.
